OctoOrgler — Lamp control

Scenes, chases and breathing for the eight OctoOrgler bulbs. Paused automatically while a game is running.

Connected through the OctoOrgler server. Gateway address and API key are set in Admin settings / .env.

Checks every 10 seconds, restores the latest requested state to lamps that dropped out, and re-sends it to lamps whose reported power or brightness has drifted. No resets or re-pairing.
Scenes — none
Motions — none
Breathing settings

Uses the selected RGB color or white temperature for the whole OctoOrgler group. Change these settings or the color, then restart Breathing to apply. Minimum brightness is 1% so lamps stay on throughout the cycle. Minimum cycle is 4 s, because group commands are Zigbee broadcasts and too many of them get dropped.

Choose a scene or motion. Click the active item again to stop it and switch the group off.

Scenes are static with no transition. Circular chases use Lamp order and Chase speed; Breathing uses its own brightness and cycle settings. Only one preset can be active.
